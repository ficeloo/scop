# Screenshots to capture

Images used by the main [README](../../README.md). Save them in this folder with **exactly** these names (PNG, about 1024×768, the default window size).

Run `make MODE=release && ./scop` from the repository root. The program starts on `resources/model/42.obj` in grey view; `M` switches to the texture, `Enter` opens another model.

| File | What it must show | How to get it |
| --- | --- | --- |
| `42_grey.png` | The 42 logo in grey view: several shades of grey visible, one per triangle | Start the program, rotate a little (`U`/`O`, `I`/`K`) so the front and the side are both visible |
| `42_textured.png` | The 42 logo with a texture | Press `M`, choose a texture with `←`/`→` |
| `transition.png` | The transition grey ↔ texture in progress (half grey, half texture) | The transition lasts only 0.2 s (`MESH_VIEW_SPEED = 5.0` in `src/app/render.rs`). Lower it for the capture (for example `0.5`), take the screenshot during the transition, then put the value back. A short GIF (`transition.gif`) also works: update the link in the README |
| `teapot.png` | The Utah teapot | `Enter` → `teapot.obj`. ⚠️ The requested "wireframe" view does not exist in the code (`PolygonMode::FILL` only): capture the grey view, or add a wireframe mode first (needs the `fillModeNonSolid` device feature) and rename the file `teapot_wireframe.png` |
| `concave_fan.png` | `concave_test.obj` **before** ear clipping: triangles drawn outside the "L" and between the branches of the star | Check out a commit before `cb4ef8b` (for example `git switch --detach d9b0936`), build, `Enter` → `concave_test.obj`, capture, then `git switch main`. At that commit culling is `BACK`: if the faces are invisible, rotate the model to see the other side |
| `concave_earclip.png` | `concave_test.obj` **after** ear clipping: a clean "L" and a clean star | Current code, `Enter` → `concave_test.obj` |
| `42_planar.png` | The 42 logo with the **planar projection**: texture stretched into stripes on the sides | Current code, press `M`, rotate to see the side of the logo |
| `42_boxmapping.png` | The 42 logo with **box mapping**: no stretching on the sides | ⚠️ Box mapping is not in the code at commit `fca6c0a`. Capture it once it is implemented, with the same angle as `42_planar.png` |

`banner.svg` is not a screenshot: it is generated by `make_banner.py` (see the top of that file).

Tips:

- Take `42_planar.png` and `42_boxmapping.png` with the same model position and the same texture, so they can be compared side by side.
- Same for `concave_fan.png` and `concave_earclip.png`.
- If you rename a file, update its link in the README (sections *Screenshots*, *3. Triangulation* and *8. Textures*).
